Keep the address the same

The Windows computer name may stay the same, but not every home router lets the iPad find devices by name. A DHCP reservation (also called address reservation or static lease) is the most reliable way to keep the iPad address fixed:

  1. Open your router's app or admin page and find Connected devices or DHCP reservations.
  2. Select this laptop from the device list. If needed, find its Wi-Fi IPv4 address in the laptop's start window or with ipconfig on Windows.
  3. Save the reservation. Then use http://reserved-address:8000 in iPad Safari and add that page to the Home Screen.

A reservation tells the router to keep giving this laptop the same address. It is safer than manually setting an arbitrary address on the laptop. Both devices still need to be on the same Wi-Fi. You need access to the router to make this one-time change. If Windows Firewall asks, allow the studio on private/home networks so the iPad can connect.

Add an icon to the Home Screen

  1. Once the studio is open in Safari at the reserved address, tap Share (the square with the up arrow).
  2. Tap Add to Home Screen. If you see Open as Web App, turn it on.
  3. Tap Add. The icon will open the studio in an app-like window.
